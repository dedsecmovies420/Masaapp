# App Lock / Theme / Notifications v2

This revision specifically improves notification reliability and call/message sound testing.

Important:
- Browser notification support depends on the browser and OS.
- Notification permission must be granted by the user.
- Browser autoplay restrictions can prevent sound until the user has interacted with the page.
- Native Android push notifications require a native Android wrapper/push service and are not supplied by GitHub Pages alone.
- This is not a substitute for production security review.
