# Production roadmap

## Phase 1 — Foundation
- [ ] Real account authentication
- [ ] HTTPS/WSS
- [ ] Persistent user directory
- [ ] Device/session management

## Phase 2 — Real E2EE
- [ ] Adopt an audited E2EE protocol/library
- [ ] Authenticated public-key exchange
- [ ] Identity verification
- [ ] Key rotation
- [ ] Multi-device support
- [ ] Encrypted attachments
- [ ] Forward secrecy / post-compromise recovery as provided by the chosen protocol

## Phase 3 — Calls
- [ ] WebRTC
- [ ] STUN/TURN
- [ ] Authenticated call signalling
- [ ] Microphone/camera permissions
- [ ] Call notifications
- [ ] Background/incoming-call handling

## Phase 4 — Android
- [ ] Native wrapper or native client
- [ ] Secure keystore-backed key storage
- [ ] Proper biometric API
- [ ] Notification channels
- [ ] Android 13+ notification permission
- [ ] Compatibility testing
- [ ] Decide a security-supported minimum Android version

## Phase 5 — Security review
- [ ] Dependency audit

- [ ] Cryptographic review
